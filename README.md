# Count Files Project

Цей проект містить набір файлів для виконання лабораторних робіт з курсу "Системне програмування та адміністрування ОС". У ньому демонструється процес збірки та тестування Bash-скрипта для підрахунку файлів у директорії `/etc`. Проект включає налаштування CI/CD пайплайну для створення RPM та DEB пакетів.

## 📋 Опис

Основний компонент проекту — скрипт `count_files.sh`, який підраховує кількість файлів у `/etc`. Проект автоматизує упаковку цього скрипта для дистрибутивів на базі Red Hat (RPM) та Debian (DEB).

## 🚀 CI/CD Пайплайн

Пайплайн налаштований у `Jenkinsfile` і виконує наступні етапи у Docker-контейнерах:

1.  **Test Script**: Перевірка синтаксису та тестовий запуск скрипта.
2.  **Build RPM**: Збірка RPM-пакету у середовищі **Fedora** за допомогою `rpmbuild`.
3.  **Build DEB**: Збірка DEB-пакету у середовищі **Ubuntu** за допомогою `dpkg-buildpackage`.
4.  **Test RPM Installation**: Перевірка встановлення та роботи RPM-пакету на **OracleLinux 8**.
5.  **Test DEB Installation**: Перевірка встановлення та роботи DEB-пакету на **Ubuntu**.

## 📦 Встановлення та Використання

### Ручний запуск скрипта
```bash
chmod +x count_files.sh
./count_files.sh
```

## Встановлення з пакетів (після збірки)

### RPM (RHEL/CentOS/Fedora):
```bash
rpm -ivh count-files-1.0-1*.noarch.rpm
count_files
```

### DEB (Debian/Ubuntu):
```bash
dpkg -i count-files_1.0-1_all.deb
count_files
```
